# Saffron plugins for Claude Code and Codex

A Claude Code and Codex plugin marketplace with one plugin, `saffron`: the Saffron
language server, MCP server and agent skill. See
[plugins/saffron/README.md](plugins/saffron/README.md).

```
/plugin marketplace add s-chathuranga-j/saffron-claude-plugin
/plugin install saffron@saffron
```

The same repo is a Codex marketplace (MCP server and skill; Codex has no
language server slot):

```
codex plugin marketplace add s-chathuranga-j/saffron-claude-plugin
codex plugin add saffron@saffron
```
