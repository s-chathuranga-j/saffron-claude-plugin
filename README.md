# Saffron plugins for Claude Code

A Claude Code plugin marketplace with one plugin, `saffron`: the Saffron
language server, MCP server and agent skill. See
[plugins/saffron/README.md](plugins/saffron/README.md).

```
/plugin marketplace add s-chathuranga-j/saffron-claude-plugin
/plugin install saffron@saffron
```
